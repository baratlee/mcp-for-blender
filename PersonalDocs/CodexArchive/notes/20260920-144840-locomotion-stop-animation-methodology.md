# LT009 停步动画修改方法论

- 适用范围：基于既有移动／停步动画进行修整，尤其是 LT009 类 Blender FBX 停步动画任务。
- 总原则：在原动画基础上修改，不重新制作动作。原动画是姿势、动作风格、全身协调以及左右脚相位结构的主基准；参考动画只用于判断速度、停止节奏和幅度方向，不直接替换原姿势。
- 必须尽量保留原动画的左右脚支撑／摆动顺序、落脚数量、起始承重脚、最终收步关系和脚掌滚动关系。允许小幅重映射相位时长，但不能交换、增加或重新组织相位来解决局部问题。
- 主要允许修改的量是时间／速度和幅度，包括 `root_M` 推进速度、制动开始／峰值／结束时机、骨盆升降、重心跟随、躯干倾角和步幅。优先采用相对原曲线的连续变换，可概括为：`新动画 = 原动画(phi(t)) + 小幅连续修正`；`phi(t)` 必须单调，并尽量固定原接触相位边界。
- 固定工作顺序：
  1. 先在保留原动作结构的前提下确定身体躯干的前移与停止节奏；不以锁脚结果反向塑造身体运动。
  2. 再参考原本左右脚相位，根据已经确定的身体轨迹小幅调整落地时刻和世界落点；最终相位保持前脚，由后脚向前跟进。
  3. 最后才做腿部反向解算。IK 只负责以最小修正满足既定落点、膝向和腿长可达性，不能主导身体节奏或重做脚步相位。
- 若 IK 不可达、膝盖异常或需要明显修改骨盆／根，应返回身体速度、幅度或落点设计阶段调整；禁止继续堆叠局部补偿。
- 分阶段门禁：先确认不依赖腿部的身体停止节奏，再确认相位与脚印规划，最后才允许 IK 和脚掌接触修整。数值锁脚不能替代整体姿势与最终蒙皮观感。
- 失败模式：依次补根曲线、锁脚、相位数量和重心姿势，会使局部指标改善但整体运动持续恶化；不得把这种补丁式流程作为后续模板。
- 状态边界：记录该方法论不代表恢复已放弃的 m002；只有用户明确重新立项后才实施。
