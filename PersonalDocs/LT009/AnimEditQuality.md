# 动画编辑质量判定：可程序化检查

2026-10-14 建立。LT009 只编辑人形或类人形动画；**每次编辑都必须满足本文的限制**（不限根运动节奏类），交付前附第 7 节的检查报告。术语见 [RootMotionRetiming.md](RootMotionRetiming.md#0-术语)。

- 只收录能用程序计算并给出“通过／不通过”的检查；观感由用户播放判定，数值全过不等于观感过。
- **原动画是标尺**：阈值尽量取自同一段原动画的实测，不套通用解剖学数字。
- 标“待标定”的阈值是初始默认值，在第一个实际案例上校准后改成定值并注明日期。
- 实现状态：**全部未实现**（截至 2026-10-14），需写成通用检查脚本。

## 1. 输入与预处理

| 项 | 内容 |
|---|---|
| 输入 | 原动画 Action（标尺）、修改后 Action；同一骨架 |
| 采样 | 全部整帧 + 半帧；用依赖图求值后的世界矩阵，不读局部 FCurve 代替 |
| 着地判定 | 脚／脚趾骨的高度与水平速度**同时**低于阈值才算着地；阈值写入报告，结果给用户过目（纯高度阈值不可靠） |
| 相位序列 | 由原动画着地区间得出落脚帧、承重脚序列 |
| 分界帧 | 按 RootMotionRetiming 由用户确认后输入 |
| 重心 | 骨盆、躯干、头、双臂、双腿加权；权重方案在首个案例固定后写入本文 |
| 改动白名单 | 合同允许修改的曲线列表（骨骼 + 通道），由合同给出 |

## 2. 合同检查（硬性）

| ID | 检查 | 计算 | 通过条件 |
|---|---|---|---|
| C1 | 时长 | 帧率、首末关键帧 | 与原动画相同 |
| C2 | 改动范围 | 逐条比对 FCurve 哈希 | 变化的曲线全部在白名单内 |
| C3 | 静止部分不变 | 分界帧之后所有骨骼世界矩阵、变形网格 | 与原动画一致，位置误差 ≤ 0.01 mm |
| C4 | 落脚帧与步数 | 修改后重新做着地判定 | 落脚次数相同；每次落脚帧与原动画相差 ≤ 1 帧（判定噪声） |
| C5 | 根曲线单调 | 移动部分逐帧前进量 | 无负值（停步动画允许为 0） |
| C6 | 收脚 | 最后一次落脚后前脚的前进轴位置 | 不后退 |

## 3. 骨骼与关节（硬性）

| ID | 检查 | 计算 | 通过条件 | 阈值来源 |
|---|---|---|---|---|
| H1 | 骨长不变 | 每帧每根骨骼世界坐标下首尾距离，与静止姿态骨长比 | 相对误差 ≤ 1e-4（数值噪声级） | 用户要求；资料中“允许腿长小幅变化”的做法不采用 |
| H1b | 无额外平移 | FCurve 审计 | 根骨、`Bip001`、IK 辅助骨以外的 `location` 曲线未改 | 平移是骨骼被拉长的主要来源 |
| H2 | 膝肘伸展 | 髋—膝—踝（肩—肘—腕）夹角 | 每个承重／摆动区间内的最大伸展 ≤ 原动画同一区间的最大伸展 | 原动画；防膝盖弹跳 |
| H2b | 膝肘不反折、弯向不变 | 膝点相对髋踝连线的偏向，与脚尖方向的夹角 | 夹角在原动画全段的范围内（+5°，待标定） | 原动画 |
| H3 | 其他关节角 | 被修改骨骼相对父骨骼的旋转，按轴分解 | 在原动画全段的最小／最大值 ±5° 内（待标定） | 原动画 |
| H4 | 不穿地 | 脚、脚趾骨（或脚部网格顶点）最低点 | ≥ min(原动画最低点, 地面) − 0.5 cm（待标定） | 原动画 |
| H5 | 旋转连续 | 相邻帧四元数点积符号、Euler 跳变 | 无 360° 翻转；无点积为负 | 动捕清理常见问题 |
| H5b | 无角速度尖峰 | 每根被修改骨骼的逐帧角速度 | 峰值 ≤ 原动画该骨峰值 × 1.2（待标定） | 原动画 |
| H6 | 约束切换平滑 | 修改量（新 − 原）在静止窗口起止前后的二阶差分 | 不出现单帧突变；上限待标定 | 逐帧独立 IK 会在约束开关处跳变 |

## 4. 承重脚

| ID | 检查 | 计算 | 通过条件 |
|---|---|---|---|
| F1 | 静止窗口 | 每个脚印上承重脚的水平世界位移 | 存在 ≥ 0.1 s（60 FPS 为 6 帧）的连续段，段内漂移 ≤ 0.5 cm（待标定） |
| F2 | 非承重脚 | — | 允许贴地滑行，不检查滑步；仍受 H4 约束 |

## 5. 运动感（可量化部分）

| ID | 检查 | 计算 | 通过条件 | 依据 |
|---|---|---|---|---|
| M1 | 修改量平滑 | 修改量曲线的二阶差分 | 低频，无高频抖动；上限待标定 | 位移层叠加可保留原动作细节 |
| M2 | 时间重映射倍率 | 若用时间扭曲 `w(t)`：局部倍率 `dw/dt` | 在 [0.5, 2] 内且连续（待标定）；不对整段等比缩放 | 均匀加速不自然 |
| M3 | 无凭空加速 | 重心前进方向加速度 | 移动部分的正向加速度峰值 ≤ 原动画同段峰值；速度不出现突变 | 水平速度误差、多出的加速最易被察觉 |
| M4 | 减速靠着地 | 重心前进方向加速度 < −ε 的帧 | 这些帧至少有一只脚着地 | 刹车只能来自地面摩擦 |
| M5 | 腾空守物理 | 双脚离地区间内重心水平速度 | 区间内变化 ≤ max(原动画同区间变化, 5 cm/s)（待标定） | 腾空时水平速度不变 |
| M6 | 骨盆下沉有限 | 骨盆高度相对原动画的差值；每个相位周期内的上下起伏幅度 | 下沉 ≤ 5 cm（待标定）；起伏幅度 ≥ 原动画的 70%（待标定） | 可压骨盆迁就腿长，但有上限并保留原起伏 |
| M7 | 落脚缓冲 | 每次落脚后若干帧内骨盆的下沉量 | ≥ 原动画同次落脚的 70%（待标定） | 保留力量感 |
| M8 | 跟随滞后 | 骨盆、躯干、头、双手、武器各自前进速度降到阈值以下的时刻 | 先后顺序同原动画；与骨盆的滞后差 ≤ 2 帧（待标定） | 跟随与重叠动作；过度会显得无力 |
| M9 | 步幅与姿态匹配 | 每步的步幅 ÷ 摆动腿髋关节屈伸幅度 | 与原动画同一步的比值相差 ≤ 20%（待标定） | 只放大位移不改姿态会有滑行感 |
| M10 | 手臂摆动相位 | 每个相位周期内肩关节前后摆动的极值帧 | 与原动画同一周期相差 ≤ 2 帧（待标定） | 用户要求手臂与脚步同步 |

## 6. 冲突时的优先级

1. 第 3 节骨骼与关节
2. 第 4 节承重脚
3. 第 2 节合同
4. 第 5 节运动感

运动感排在最后，但不能直接放弃：前三类都过、运动感明显变差时，回退调节奏或幅度，不在局部打补丁。

## 7. 报告格式

每次修改后输出一张表，每行一个检查：

| ID | 原动画值 | 修改后值 | 阈值 | 结果 |
|---|---|---|---|---|

另附关键帧侧视／正视截图，以及重心、双脚、双手的运动轨迹图，供用户播放判定时对照。

## 资料来源

调研于 2026-10-14，结论均为转述，未逐篇细读全文：

- 位移层与时间扭曲：Witkin & Popović “Motion Warping”（1995）；Bruderlin & Williams “Motion Signal Processing”（1995）；Hsu 等 “Guided Time Warping”（2007）。
- 滑步清理与约束切换：Kovar 等 “Footskate Cleanup for Motion Capture Editing”（2002）；UnderPressure（2022）。
- 骨盆与 IK 上限：UE “Pose Warping / Stride Warping” 文档。
- 感知：Harrison 等（2004，骨长变化在注视下 3% 可察觉）；Reitsma & Pollard（2003，跳跃动作中水平速度误差、多出的加速更易察觉；能否推广到走跑停未验证）。
- 物理一致性：Popović & Witkin “Physically Based Motion Transformation”（1999）。
